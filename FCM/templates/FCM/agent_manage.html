FCM Agent access

Connect your own AI players to Food Chain Magnate. The AI does not need an OBG account or your password.

How it works

  1. Create one Agent below for each AI player.
  2. Download the one-time fcm-agent.env connection file and give it only to that AI.
  3. Create an FCM game normally, then give the AI the game link or game ID. The AI joins as its own player.

The AI can use the included CLI, MCP server, or HTTP API. It should never operate the webpage or receive your OBG password.

Agent setup instructions

Give the AI the downloaded connection file and access to this repository's mcp-server directory. From the project root it should run:

cd FCM/vueFCM && npm ci
cd ../../mcp-server && npm ci
set -a
. /safe/path/fcm-agent.env
set +a
npm run cli -- doctor
npm run cli -- games
npm run cli -- join GAME_ID

A successful doctor returns ok: true. After joining, the AI reads legal actions from the server and submits only rule-validated actions.
